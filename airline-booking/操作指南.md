## 1. 界面总览

### 页面布局

```
┌──────────────────────────────────────────────────────┐
│  ✈ Air SkyLine     航线: 23   可订座位: xxx   候补: x │  ← 头部 (品牌 + 实时统计)
├──────────────────────────────────────────────────────┤
│  📊总览 │ 🔍搜索 │ 🎫预订 │ 📋订单管理 │ ➕录入航班   │  ← Tab 导航栏
├──────────────────────────────────────────────────────┤
│                                                      │
│                  当前 Tab 内容区                       │  ← 主内容区
│                                                      │
├──────────────────────────────────────────────────────┤
│  ✈ Air SkyLine  ·  v2.3  ·  版权所有 © 2026          │  ← 页脚
└──────────────────────────────────────────────────────┘
```

### 头部统计栏

页面顶部实时显示三项核心数据：

| 指标 | 含义 |
|------|------|
| **航线** | 系统中已录入的航班总数 |
| **可订座位** | 所有航班剩余座位总和 |
| **候补旅客** | 所有航班候补队列中等待的总人数 |

这些数值在每次操作（订票、退票、候补、录入）后自动更新。

### Tab 导航

五个 Tab 对应系统的五大功能模块。点击任一 Tab 切换页面，当前激活的 Tab 下方有滑动指示条。切换 Tab 时相关数据会自动刷新。

### 通用 UI 元素

- **Toast 通知**: 右下角弹出，最多显示 5 条，3 秒后自动消失。颜色表示类型：🟢成功 / 🟡警告 / 🔴错误 / 🔵信息
- **确认对话框**: 退票、取消航班等危险操作会弹出自定义确认框，避免误操作
- **返回顶部按钮**: 页面滚动超过 500px 时右下角出现 ↑ 按钮

## 2. Tab 1 — 航班总览

> 📊 系统首页，集快捷搜索与全部航线概览于一体

### 2.1 Hero 快捷搜索区

位于页面顶部，深色渐变背景。

| 字段 | 说明 |
|------|------|
| **出发城市** | 输入城市名，支持模糊匹配（如输入"北京"匹配所有北京始发航班）|
| **到达城市** | 同上，可留空表示不限 |
| **出发日期** | 可选，精确匹配特定日期 |
| **旅客人数** | 搜索至少能满足该人数的航班 |
| **🔍 搜索航班** | 点击执行搜索，结果以卡片形式展示在下方 |

**搜索结果卡片**包含：
- 航线信息（城市 + 三字码）+ 飞行时长
- 日期、时刻、机型
- 三档票价（头等舱 / 商务舱 / 经济舱）
- 余票进度条（绿色=充足，黄色=紧张，红色=满员）
- 🎫 **预订**按钮（有余票）或 📝 **候补**按钮（满员时）

点击预订按钮将**自动跳转至预订页**并选中对应航班。

### 2.2 全部航线汇总表

以表格形式列出系统中所有航班，每行显示：

| 列 | 内容 |
|----|------|
| 航班号 | 加粗显示 |
| 航线 | 始发站 → 终点站 |
| 机型 | 如 B787-9 |
| 飞行日期 | YYYY-MM-DD |
| 时刻 | 起飞–到达 |
| 运力 | 总座位数 |
| 余票 | 当前可订座位数 |
| 状态 | 有票🟢 / 仅剩X座🟡 / 满员🔴 / 已取消⚫ |
| 操作 | **详情**按钮 + **取消航班**按钮 |

点击任意行或 **详情** 按钮可展开子表，显示该航班的：
- 📋 **已订票客户名单**（按姓名排序的链表）：姓名、票数、舱位、座位号、PNR、旅客类型
- ⏳ **候补队列**（链式队列 FIFO）：序号、姓名、需票数、舱位偏好、联系方式、登记时间

### 2.3 底部操作按钮

| 按钮 | 功能 |
|------|------|
| 🔄 恢复测试数据 | 清空当前数据并重新初始化 23 条测试航线 |
| 📥 导出数据 | 将所有数据导出为 JSON 文件下载到本地 |
| 📤 导入数据 | 从本地 JSON 文件导入数据（覆盖当前数据） |

## 3. Tab 2 — 搜索航班

> 🔍 高级多维搜索，支持 12 种筛选条件的精准航班定位

### 3.1 基本搜索条件

| 字段 | 说明 |
|------|------|
| **出发城市** | 下拉选择，列表来自系统中所有始发站 |
| **到达城市** | 下拉选择，列表来自系统中所有终点站 |
| **航班号** | 可选，模糊匹配（如输入 `CA1` 匹配 CA1001、CA1003 等）|
| **出发日期** | 可选，精确匹配 |
| **旅客人数** | 搜索至少能满足该人数的航班 |
| **🔍 搜索** | 执行搜索 |

### 3.2 高级筛选面板

点击 **⚙ 高级筛选 ▾** 展开面板，提供以下过滤条件：

#### 🌅 出发时段
单选 chip 按钮组：

| 选项 | 时段范围 |
|------|---------|
| 全部 | 06:00–05:59 (次日) |
| 🌅 早班 | 06:00–11:59 |
| ☀ 午班 | 12:00–17:59 |
| 🌙 晚班 | 18:00–23:59 |
| 🌃 夜航 | 00:00–05:59 |

#### 💰 价格区间
- **最低价 / 最高价**：数值输入框
- **舱位选择**：指定按哪个舱位的价格筛选（经济/商务/头等）
- **清除**按钮重置价格输入

#### ✈ 机型
多选 chip 按钮组（最多选 3 种），列出系统中所有机型如 `B787-9`、`A350-9`。

#### 📋 其他选项
- **包含满员航班**：默认勾选，取消后只显示有余票的航班
- **包含已取消航班**：默认不勾选

#### 快捷标签栏
搜索栏下方提供一键筛选 chips：

| 快捷标签示例 | 效果 |
|-------------|------|
| 💰 经济舱 ≤¥XXX | 按价格上限筛选 |
| ⏰ 早班出发 | 仅看早班 |
| 💺 余票≥10 | 只看余票充足的航班 |

### 3.3 搜索结果

结果以卡片列表展示，每张卡片同总览页的搜索结果格式。顶部有排序下拉框，支持：

- 默认顺序
- 经济舱价格 ↑/↓
- 商务舱价格 ↑/↓
- 头等舱价格 ↑/↓
- 起飞时间早→晚 / 晚→早
- 飞行时长短→长
- 余票多→少

搜索无结果时，系统会智能推荐**附近日期**的航班，并提示放宽筛选条件。

## 4. Tab 3 — 预订客票

> 🎫 三步订票流程，支持可视化选座和跨舱位多旅客预订

### 步骤进度条

```
  ① ────── ② ────── ③
选择航班   填写信息   确认结果
```

### 步骤 1：选择航班

1. 从下拉列表选择航班（显示航班号、航线、日期、余票，已取消航班灰色不可选）
2. 点击 **确认选择 →**
3. 系统展示**登机牌风格**的航班预览卡，包含：
   - 航线 + 机场三字码
   - 航班号、日期、时刻、机型
   - 余票情况、三舱票价

### 步骤 2：旅客信息 & 选座

步骤 1 完成后，步骤 2 自动解锁。

#### 旅客信息（左侧）

**单选模式**（未手动选座时）：
- 旅客姓名、旅客类型（成人/儿童 75%/婴儿 10%）、订票数量、舱位等级、联系方式

**多选模式**（点击座位后自动切换）：
- 每座一行，独立填写旅客姓名和类型
- 舱位由座位位置自动决定（支持跨舱位混合选座）
- 实时汇总：`已选 3 座: 头等×1 + 经济×2`

#### 可视化座位图（右侧）

座位图采用**液态玻璃机身**设计，分为三个舱位区域：

| 舱位 | 颜色 | 布局 | 座位 |
|------|------|------|------|
| 🟡 头等舱 | 金色 | 1-2-1 | 第1-2排 |
| 🔵 商务舱 | 蓝灰 | 2-2 | 第3-5排 |
| 🟢 经济舱 | 绿色 | 3-3 | 第6+排 |

- 🚪 橙色高亮行 = 紧急出口排（额外腿部空间）
- 过道用空白分隔
- 鼠标悬停座位显示 tooltip：座位号 · 舱位名称 · 票价 · 靠窗/过道/额外空间
- **点击座位直接选中/取消**（支持跨舱位多选，无上限）
- 灰色 ✕ = 已占用

#### 图例说明
- 头等舱 | 商务舱 | 经济舱 | 已占用 | 紧急出口

#### 价格实时计算
- 选择座位后，舱位自动确定（不从下拉框读取）
- 每座按实际舱位 + 旅客类型折扣独立计价
- 座位图上方显示实时价格摘要：`已选 X 座 | 头等×Y+经济×Z | 合计 ¥XX,XXX`

#### 确认预订

点击 **🎫 确认预订** 按钮：
- 多选模式：预校验（姓名完整 + 不重复 + 余票充足 + 座位未被抢）→ 逐人下单
- 余票不足时自动提示加入候补队列

### 步骤 3：确认结果

预订成功后展示 **PNR 确认卡**：

**单选模式**显示一张 PNR 卡：
- 🎫 PNR 参考号（金色大字，如 `T000XK`）
- 旅客、航班、航线、日期、时刻、舱位、座位、票数、总价、订票时间

**多选模式**显示多张 PNR 卡 + 合计金额：
- 每位旅客独立 PNR
- 各自舱位标签和旅客类型
- 总价汇总

> ⚠️ **请妥善保存 PNR 参考号**，用于后续值机、退票或改签。8 秒后表单自动重置。

## 5. Tab 4 — 订单管理

> 📋 集中管理已订票订单：PNR 查询/退票、按姓名退票、候补队列查看

### 5.1 按 PNR 查找/退票（推荐）

1. 在输入框输入 **6 位 PNR 参考号**（如 `T000XK`，自动转大写）
2. 点击 **🔍 查询订单**
3. 显示完整订单信息卡：
   - PNR 号、旅客、航班、航线、日期时刻
   - 舱位、旅客类型（儿童/婴儿会标注折扣价）
   - 座位号、票数、票价、订票时间
4. 确认无误后点击 **💵 办理退票**

退票成功后：
- 释放的票额会自动分配给候补队列中的客户（FIFO 顺序）
- 页面显示候补补位详情（谁补到了、几张票、新 PNR）

### 5.2 按航班+姓名退票

1. 从下拉选择**航班号**
2. 系统自动加载该航班的已订票客户列表到**客户姓名**下拉框
3. 选择客户（显示姓名、票数、PNR）
4. 点击 **💵 确认退票** → 弹出确认对话框 → 确认后退票
5. 同样会触发候补自动补位

### 5.3 候补队列查询

1. 选择航班号
2. 点击 **查看候补队列**
3. 以表格展示候补名单：

| 序号 | 姓名 | 需票 | 舱位 | 联系方式 | 登记时间 |
|------|------|------|------|---------|---------|
| 1 | 刘鹏飞 | 2 | 经济舱 | 138**** | 2026-06-... |

> 💡 序号 1 是队头，**优先获得**退票释放的票额。

## 7. 常见操作流程

### 7.1 快速订票（推荐路径）

```
首页 Hero 搜索 → 找到航班 → 点击"预订" → 自动跳转预订页
→ 选座(可选) → 填信息 → 确认预订 → 获得 PNR
```

### 7.2 高级搜索订票

```
搜索航班 Tab → 设置始发/终点 → 展开高级筛选 → 设置时段/价格/机型
→ 搜索 → 排序 → 点击"预订" → 填信息选座 → 确认 → 获得 PNR
```

### 7.3 满员航班候补

```
搜索到满员航班 → 点击"候补" → 弹出模态框 → 填姓名/票数/舱位/联系方式
→ 确认加入 → 等待有人退票时自动补位
```

### 7.4 PNR 退票

```
订单管理 Tab → 输入 PNR → 查询订单 → 确认信息 → 办理退票
→ 系统自动从候补队列补位
```

### 7.5 取消航班

```
航班总览 Tab → 找到目标航班 → 点击"取消航班" → 确认对话框
→ 自动退票所有旅客 + 清空候补队列
```

### 7.6 数据备份

```
航班总览 Tab → 点击"📥 导出数据" → 下载 JSON 文件到本地
```

### 7.7 数据恢复

```
航班总览 Tab → 点击"📤 导入数据" → 选择之前导出的 JSON 文件
```
或直接点击 **🔄 恢复测试数据** 重置为系统内置的 23 条测试航线。

## 8. 数据管理

### 持久化机制

所有数据自动保存在浏览器 `localStorage` 中（键名 `airline_v2_data`），关闭浏览器后数据不丢失。

### 测试数据

系统内置 **23 条测试航线**：

| 类别 | 数量 | 示例 |
|------|------|------|
| 国内·北京始发 | 8 条 | PEK→SHA、PEK→CAN、PEK→SZX... |
| 国内·上海始发 | 4 条 | SHA→PEK、SHA→CAN、SHA→SYX... |
| 国内·广州始发 | 4 条 | CAN→PEK、CAN→SHA... |
| 国际·亚洲短途 | 5 条 | PEK→NRT、PEK→ICN、PEK→BKK... |
| 国际·长途 | 3 条 | PEK→LHR、PEK→DXB、PEK→SYD |

其中 6 条航班为满员 + 带候补队列，8 条为高密度 (85-95%)，其余为中等填充 (65-80%)。

### 数据结构说明

| 需求 | 实现 |
|------|------|
| 航线汇总表 | 数组顺序存储，按航班号有序 |
| 已订票客户名单 | 按姓名排序的单链表 (`SortedLinkedList`) |
| 候补客户名单 | 链式队列 FIFO (`LinkedQueue`) |

## 9. 提示与注意事项

### 💡 使用技巧
- **Hero 搜索**支持回车键快捷触发
- 搜索页的**排序下拉**可对结果即时排序，无需重新搜索
- 选座时**直接点击座位**即可，支持跨舱位混合选择
- 快捷标签栏可**一键设置**常用筛选条件
- 搜索结果无匹配时会**智能推荐附近日期**的航班

### ⚠️ 注意事项
- 同一航班上**同姓名不能重复订票**（如需多张票请一次性预订）
- PNR 参考号是退票的**唯一凭证**，请妥善保存
- 退票后 PNR 立即作废，**不可撤销**
- 候补补位按 **FIFO 顺序**：队头需求量 ≤ 余票时才补位，否则保持顺序等待
- 取消航班后**无法恢复**（除非重新导入数据）
- 导入数据会**覆盖**当前所有数据，建议先导出备份
- 儿童票价为成人 75%，婴儿为 10%

### 📱 兼容性
- 支持所有现代浏览器（Chrome、Firefox、Safari、Edge）
- 纯前端实现，无需网络连接
- 数据存储在浏览器本地，**不同设备/浏览器数据不互通**
