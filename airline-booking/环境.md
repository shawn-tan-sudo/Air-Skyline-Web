## 2.2 存储结构设计

### 2.2.1 航线汇总表 — 顺序存储结构

`AirlineSystem.flights` 为 `Flight[]` 数组，按航班号字典序升序排列。

**插入算法** — `addFlight()`

1. 调用 `findIndex(x => x.flightNo.localeCompare(f.flightNo) > 0)` 查找第一个航班号大于新航班的位置 `idx`
2. 若 `idx === -1` (所有现有航班号均 ≤ 新航班): `push` 到数组末尾
3. 否则: `splice(idx, 0, f)` 插入到 `idx` 位置
4. 调用 `_persist()` 持久化

**查找算法** — `findFlight()`

1. 使用 `Array.find()` 顺序遍历 `flights` 数组
2. 比较 `f.flightNo === flightNo`
3. 找到返回 `Flight` 对象，否则返回 `undefined`

> **复杂度**: 插入 O(n)，查找 O(n)。航线数量有限 (n < 100)，顺序搜索效率足够。

## 2.4 座位图生成算法 — `getSeatMap()`

### 三舱分区规则

设 `totalRows = ceil(capacity / 6)`：

```
头等舱首排    = 1
头等舱末排    = min(2, totalRows)
商务舱首排    = 头等舱末排 + 1
商务舱末排    = 头等舱末排 + min(3, max(0, totalRows - 头等舱末排))
经济舱首排    = 商务舱末排 + 1
经济舱末排    = totalRows
紧急出口排    = [经济舱首排, min(经济舱首排 + 10, totalRows)]
```

### 座位布局

| 舱位 | 每排列 | 列序 | 布局标注 |
|:---|:---|:---|:---|
| 头等舱 | 4 座 | A, C \| 过道 \| D, F | `1-2-1` |
| 商务舱 | 4 座 | A, C \| 过道 \| D, F | `2-2` |
| 经济舱 | 6 座 | A,B,C \| 过道 \| D,E,F | `3-3` |

### 座位特征判定

* A 列或 F 列 → 标记 `window` (靠窗)
* C 列或 D 列 → 标记 `aisle` (过道)
* 所在排 ∈ exitRows → 标记 `extra_legroom` (额外腿部空间)

### 算法流程

```
        ┌──────────────────┐
        │ occupiedSeats()  │  ← 获取已占用座位集合
        └────────┬─────────┘
                 ▼
        ┌──────────────────┐
        │ 计算 totalRows    │
        │ 划分三区排数       │
        └────────┬─────────┘
                 ▼
    ┌────────────────────────────────────┐
    │ 对每个舱位分区:                      │
    │   for head 舱: 1-2-1 布局 4座      │
    │   for business 舱: 2-2 布局 4座    │
    │   for economy 舱: 3-3 布局 6座     │
    │                                    │
    │   对每个座位调用 makeSeat():         │
    │     · 判定是否被占用                 │
    │     · 判定是否存在(globalIdx≤capacity)│
    │     · 判定特征(window/aisle/legroom) │
    └───────────────┬────────────────────┘
                    ▼
        ┌───────────────────────┐
        │ 输出 zones[]           │  ← [{name, className, cabinClass,
        │                         │       color, bg, rows}, ...]
        │ 输出 exitRows[]        │  ← 紧急出口排编号
        │ 输出 totalRows         │
        └───────────────────────┘
```

## 2.6 数据持久化设计

**存储键**: `localStorage` 键名 `"airline_v2_data"`

### 序列化 — `_persist()`

```
flights[] → map → 每条航班展开为:
{
  基础字段: origin, originCode, destination, destCode,
           flightNo, planeNo, flightDate,
           departureTime, arrivalTime,
           capacity, prices, remaining
  bookedList:  toArray() → [{name, ticketCount, cabinClass,
                             seatNumbers, pnr, bookingTime,
                             passengerType, contact}, ...]
  waitQueue:   toArray() → [{position, name, ticketCount,
                             cabinClass, contact, enqueueTime}, ...]
}
→ JSON.stringify → localStorage.setItem("airline_v2_data", json)
```

### 反序列化 — `load()`

```
localStorage.getItem("airline_v2_data")
→ JSON.parse
→ for each d in data[]:
    1. new Flight(各基础字段)
    2. f.remaining = d.remaining
    3. for each c in d.bookedList[]:
         f.bookedList.insert(各字段) → 逐个重建链表节点
    4. for each w in d.waitQueue[]:
         f.waitQueue.enqueue(各字段) → 逐个重建队列节点
    5. this.flights.push(f)
```

> **兼容性说明**: 旧版本数据 (含 `weekday` 字段) 与新版本 (`flightDate` 字段) 不兼容。首次运行或数据格式不匹配时自动回退到 `initTestData()`。

## 2.10 座位编号规则

每排 6 座，列标 A ~ F。第 N 张票的座位号计算公式：

```
row    = ceil(N / 6)
column = ['A','B','C','D','E','F'][(N - 1) % 6]
座位号  = row + column
```

示例: N=1→1A, N=2→1B, N=6→1F, N=7→2A, N=12→2F

自动分配时从 `bookedCount + 1` 开始编号，确保新票座位紧接已有订票之后。
