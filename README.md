# SkyLine 航空客运订票系统 — 需求分析

> **版本**: v2.2 | **更新时间**: 2026-06-16

## 项目分层架构

```
┌──────────────────────────────────────┐
│  index.html   (页面骨架 · 5个Tab)      │  展示层
│  app.js       (DOM交互 · 事件驱动)     │
├──────────────────────────────────────┤
│  airline-system.js (核心业务逻辑)      │  业务层
├──────────────────────────────────────┤
│  data-structures.js (链表/队列)       │  数据层
├──────────────────────────────────────┤
│  style.css    (视觉设计)              │  样式层
└──────────────────────────────────────┘
```

## 模块一: `data-structures.js` — 基础数据结构

> 纯数据结构，无业务逻辑，被业务层依赖

### 1.1 `CustomerNode` — 已订票客户节点

| 需求 | 说明 |
|------|------|
| 存储客户信息 | 姓名、票数、舱位等级(1/2/3)、座位号数组、PNR参考号、订票时间、旅客类型(成人/儿童/婴儿)、联系方式 |
| 链表链接 | 持有 `next` 指针，支持单向链表遍历 |

### 1.2 `SortedLinkedList` — 按姓名排序的已订票客户链表

| 功能需求 | 说明 |
|----------|------|
| **按姓名有序插入** | `insert()` — 使用 `localeCompare(name, 'zh')` 做中文拼音排序，维护链表有序性 |
| **按姓名查找** | `search(name)` — 顺序遍历，返回节点或 null |
| **按姓名删除** | `delete(name)` — 删除指定姓名节点，维护链表完整性 |
| **按PNR查找** | `searchByPNR(pnr)` — 遍历匹配PNR，用于退票/查询场景 |
| **按PNR删除** | `deleteByPNR(pnr)` — 按PNR移除节点，用于退票 |
| **统计总订票数** | `getTotalBooked()` — 遍历累加所有节点的 ticketCount |
| **序列化导出** | `toArray()` — 将链表转为纯对象数组，供 `localStorage` 持久化 |

### 1.3 `WaitNode` — 候补客户队列节点

| 需求 | 说明 |
|------|------|
| 存储候补信息 | 姓名、所需票数、舱位偏好、联系方式、入队时间(自动生成) |
| 链表链接 | 持有 `next` 指针 |

### 1.4 `LinkedQueue` — 候补客户链式队列 (FIFO)

| 功能需求 | 说明 |
|----------|------|
| **入队** | `enqueue()` — 队尾追加新节点，维护 `front`/`rear` 双指针 |
| **出队** | `dequeue()` — 队头移除，先进先出 |
| **查看队头** | `peek()` — 不移除地获取队头节点 |
| **按姓名移除** | `removeByName()` — 遍历队列删除指定姓名(候补取消场景) |
| **判空/计数** | `isEmpty()` / `size` |
| **序列化导出** | `toArray()` — 含位置序号 `position` |

## 模块二: `airline-system.js` — 核心业务逻辑

### 2.1 `Flight` 类 — 航线记录

| 功能需求 | 说明 |
|----------|------|
| **存储8个信息域** | 始发站+三字码、终点站+三字码、航班号、机型、飞行日期(YYYY-MM-DD)、起飞/到达时刻(HH:MM)、乘员定额、三级票价 |
| **余票管理** | `remaining` 字段跟踪可售票数，`isFull` / `bookedCount` getter |
| **座位自动分配** | `generateSeatNumbers(count)` — 从已售票数起点顺序生成座位号(每排6座A-F) |
| **已占用座位查询** | `occupiedSeats()` — 遍历已订票链表，返回被占用座位号 Set |
| **可视化座位图** | `getSeatMap()` — 按三舱分区(头等1-2排1-2-1/商务3-5排2-2/经济6+排3-3)，标记紧急出口排，每个座位含特征(window/aisle/extra_legroom) |
| **票价查询** | `getPrice(cabinClass)` — 按舱位返回票价 |
| **持有两个链式结构指针** | `bookedList`(SortedLinkedList) + `waitQueue`(LinkedQueue) |

### 2.2 `AirlineSystem` 类 — 订票系统主控

#### 航班管理

| 功能需求 | 说明 |
|----------|------|
| **录入航班** | `addFlight()` — 按航班号有序插入 `flights` 数组(顺序存储)，自动持久化 |
| **查找航班** | `findFlight(flightNo)` — 顺序搜索返回 Flight 对象 |
| **获取机场列表** | `getAirports()` — 去重返回所有始发站/终点站(含三字码)，供下拉菜单使用 |

#### PNR 生成

| 功能需求 | 说明 |
|----------|------|
| **生成唯一PNR** | `_generatePNR()` — 6位字母数字混合(排除I/O/0/1)，循环检查全局唯一性 |
| **PNR唯一性校验** | `_pnrExists(pnr)` — 遍历所有航班的已订票链表 |

#### 航线搜索

| 功能需求 | 说明 |
|----------|------|
| **按航线搜索** | `searchFlights(origin, dest, date?)` — 模糊匹配始发/终点站，可选按飞行日期精确过滤，返回含票价+余票+候补人数的结果数组 |

#### 订票 (核心)

| 功能需求 | 说明 |
|----------|------|
| **验票订票** | `bookTicket()` — 查航班→验余票→查同名冲突→生成PNR→分配座位(支持手动选座/自动分配)→插入已订票链表→扣减余票→持久化 |
| **旅客类型折扣** | 成人100%、儿童75%、婴儿10% — 价格计算自动应用乘数 |
| **跨舱位计价** | 支持每座独立舱位价格 + 类型折扣的混合计算 |
| **同名防重** | 同一航班禁止同名重复订票 |
| **候补引导** | 余票不足时返回 `canWaitlist: true`，引导用户加入候补 |
| **加入候补** | `joinWaitlist()` — 验重后入队，返回排队位置 |

#### 退票 (含候补自动补位)

| 功能需求 | 说明 |
|----------|------|
| **按姓名退票** | `refundTicket(flightNo, name)` — 从已订票链表删除→释放票额→触发候补处理 |
| **按PNR退票** | `refundByPNR(pnr)` — 推荐方式，全局搜索PNR→退票 |
| **PNR查询** | `lookupByPNR(pnr)` — 返回完整订票详情(含折扣后票价) |
| **候补自动补位** | `_processRefund()` — 退票后 while 循环: peek队头→需求≤余票? dequeue+生成PNR+插入已订票 / 否则break |

#### 统计与持久化

| 功能需求 | 说明 |
|----------|------|
| **系统统计** | `stats()` — 航线数/总运力/已售/剩余/候补总人数 |
| **数据持久化** | `_persist()` — `flights` → `JSON.stringify` → `localStorage` 键 `airline_v2_data` |
| **数据加载** | `load()` — 从 localStorage 反序列化→重建 Flight 对象→重建链表/队列结构 |
| **清空数据** | `clearAll()` — 清空 flights + 移除 localStorage |
| **测试数据** | `initTestData()` — 17条航线(北京/上海/广州始发)+预置订票+候补数据 |

## 模块三: `index.html` — 页面骨架

### 3.1 全局布局

| 需求 | 说明 |
|------|------|
| **Header** | 品牌标识 + 实时统计(航线数/可订座位/候补人数) |
| **Tab导航** | 5个Tab按钮，通过 `data-tab` 属性关联内容区 |
| **Toast容器** | 全局通知浮层 |

### 3.2 五个Tab页面

| Tab | ID | 功能需求 |
|-----|-----|---------|
| ① 航班总览 | `tab-overview` | Hero快捷搜索(始发/终点/日期) + 全部航线汇总表(含展开查看已订票+候补详情) + 恢复测试数据按钮 |
| ② 搜索航班 | `tab-search` | 高级搜索(下拉选机场+日期) + 结果表格(含三舱价格+预订/候补按钮) |
| ③ 预订客票 | `tab-book` | 三步流程: 选航班→填旅客信息+可视化选座→PNR确认卡 |
| ④ 订单管理 | `tab-manage` | PNR查询/退票 + 按航班+姓名退票 + 候补队列查看 |
| ⑤ 录入航班 | `tab-add` | 完整表单: 始发/终点+三字码+航班号+机型+日期+时刻+运力+三级票价 |

### 3.3 订票表单双模式

| 模式 | 触发条件 | 表单结构 |
|------|---------|---------|
| **单选模式** `#single-pax-form` | 未选座时 | 统一填: 姓名/类型/数量/舱位 |
| **多选模式** `#multi-pax-form` | 已选N个座位时 | 逐座生成N行: 座位徽章+舱位标签+姓名输入+类型选择 |

## 模块四: `app.js` — 前端交互层

### 4.1 初始化 & Tab切换

| 功能需求 | 说明 |
|----------|------|
| **启动加载** | `DOMContentLoaded` → `sys.load()`(优先) 或 `initTestData()` → 初始化Tab/事件/机场列表/统计 |
| **Tab切换** | `switchTab()` — 去激活全部→激活目标，切换时触发对应数据刷新 |
| **机场列表** | `populateAirportLists()` — 填充 datalist 用于输入建议；`populateSearchSelects()` — 填充搜索下拉 |

### 4.2 航班总览 (`tab-overview`)

| 功能需求 | 说明 |
|----------|------|
| **总览表渲染** | 全部航班行列: 航班号/航线/机型/日期/时刻/运力/余票/状态(满员/仅剩/有票)/候补标记 |
| **展开/收起详情** | 点击行展开子表: 已订票客户(姓名/票数/舱位/座位/PNR/类型) + 候补队列(序号/姓名/需票/舱位/联系方式/登记时间) |
| **Hero快捷搜索** | 输入始发/终点(支持 datalist 建议)+可选日期→调用 `searchFlights`→渲染结果 |
| **恢复测试数据** | `resetAll()` — 确认后清空→重新init→刷新全部UI |

### 4.3 搜索航班 (`tab-search`)

| 功能需求 | 说明 |
|----------|------|
| **高级搜索** | 下拉选机场(含三字码)+(可选日期)→调用 `searchFlights` → 渲染含排序控件的结果表 |
| **8种排序** | 默认顺序 / 三舱价格各升降序(6种) / 起飞时间早晚(2种) — `sortResults()` |
| **预订/候补按钮** | 搜索结果行: 有票时"预订"按钮跳转订票Tab并自动选中航班; 满员时"候补"按钮弹窗收集姓名+数量 |

### 4.4 预订客票 (`tab-book`) — 三步流程

#### 步骤1: 选择航班

| 功能需求 | 说明 |
|----------|------|
| 航班下拉 | 显示航班号/航线/日期/余票 |
| 确认选择 | `onSelectFlight()` → 展示航班预览卡片 + 渲染座位图 + 解锁步骤2 |

#### 步骤2: 旅客信息 & 可视化选座

| 功能需求 | 说明 |
|----------|------|
| **座位图渲染** | `renderSeatMap()` — 液态玻璃机身CSS + 三舱分区标题(头等金/商务蓝灰/经济绿) + 梯形3D座位 + 过道分隔 + 紧急出口标记 + 机尾机型标识 |
| **座位特征标记** | 蓝色圆点=靠窗 / 紫色圆点=过道 / 橙色圆点=额外空间 |
| **Tooltip悬停** | 显示座位号·舱位·票价·特征文字 |
| **"右驱左"交互** | 点击座位直接多选(不限舱位/数量)→左侧表单跟随切换模式→`renderPassengerForms()` 驱动全部 |
| **单选表单** | 统一姓名/类型(成人/儿童/婴儿)/数量/舱位 |
| **多乘客表单** | 逐座生成: 座位徽章(金/蓝灰/绿) + 舱位票价标签 + 独立姓名输入 + 独立类型选择 |
| **舱位汇总** | 显示"已选N座: 头等×a + 商务×b + 经济×c" |
| **实时价格计算** | `updatePriceDisplay()` — 多选模式逐座按舱位×旅客类型乘数独立计价; 单选模式统一舱位×数量×类型乘数; 座位图上方显示合计 |
| **事件委托** | `#multi-pax-list` 上 `change` 事件监听 `.pax-type` 选择变化→刷新价格 |
| **表单联动** | 舱位/数量/旅客类型变化→触发价格刷新; 座位选中/取消→触发表单模式切换 |

#### 步骤3: 确认预订

| 功能需求 | 说明 |
|----------|------|
| **单选模式预订** | 验证姓名→调用 `bookTicket`→显示PNR确认卡(金色登机牌风格):旅客/航班/航线/日期/时刻/舱位/座位/票数/总价/PNR/订票时间 |
| **多选模式预订** | 逐人验证姓名+防同名→逐人调用 `bookTicket`(每人1票)→`showMultiBookingResult()` 显示每人独立PNR卡+合计总价 |
| **候补引导** | 余票不足时显示候补入口按钮→调用 `joinWaitlist` |
| **重置预订** | `resetBooking()` — 清空选中/表单/座位图/价格摘要 |

### 4.5 订单管理 (`tab-manage`)

| 功能需求 | 说明 |
|----------|------|
| **PNR查询** | `doPNRLookup()` — 输入PNR→调用 `lookupByPNR`→显示完整订单详情(含折扣价+旅客类型折扣标签) + 显示退票按钮 |
| **PNR退票** | 确认后→调用 `refundByPNR`→显示结果(含候补自动补位详情) |
| **按姓名退票** | 选航班→联动加载该航班已订票客户下拉→选姓名→确认退票 |
| **候补查看** | 选航班→调用 `waitQueue.toArray()`→渲染候补队列表(队头优先) |

### 4.6 录入航班 (`tab-add`)

| 功能需求 | 说明 |
|----------|------|
| **表单验证** | 始发/终点/航班号/飞机号必填; 乘员定额>0; 航班号去重 |
| **自动三字码** | 未填时代码取城市名前3字符转大写 |
| **成功反馈** | 录入成功→显示结果→清空表单→刷新全部UI |

### 4.7 全局功能

| 功能需求 | 说明 |
|----------|------|
| **实时统计** | Header三指标实时更新(航线数/可订座位/候补人数) |
| **Toast通知** | 3秒自动消失的成功/警告/错误/信息通知 |
| **HTML转义** | `esc()` 防XSS |
| **旅客类型名称** | `passengerTypeName()` — adult→成人/child→儿童/infant→婴儿 |

## 模块五: `style.css` — 视觉设计

| 需求 | 说明 |
|------|------|
| **设计语言** | 参考阿联酋/卡塔尔/新加坡航空: 午夜蓝(`#0d1b2a`)+香槟金(`#c8963e`)+磨砂玻璃卡片 |

| **座位特征点** | `.seat-feature` 5px圆点指示器(蓝/紫/橙) |
| **多乘客表单** | `.passenger-row` + `.pax-seat-badge` 三舱配色 + `.cabin-summary` 磨砂汇总条 |
| **响应式** | 基础Grid/Flex自适应，移动端折叠 |
| **组件命名** | BEM-ish: `.hero-search` / `.pnr-card` / `.seat-legend` / `.toast-container` |

## 数据结构对应关系

| 需求描述 | 实现 | 存储结构 |
|---------|------|---------|
| 航线汇总表 | `AirlineSystem.flights` (Array) | 顺序存储，按航班号有序 |
| 已订票客户名单 | `Flight.bookedList` (SortedLinkedList) | 按姓名排序的链表 |
| 等候替补客户名单 | `Flight.waitQueue` (LinkedQueue) | 链式队列，front/rear 指针 |
| 每条航线信息 | `Flight` 类属性 | 含指向两个链式结构的指针 |

├── index.html               — 页面骨架，5个Tab分页

```
data-structures.js → airline-system.js → app.js
     (无依赖)          (依赖前者)        (依赖前两者)
```

## 运行方式

```bash
# 直接双击打开
open index.html

# 或使用任意 HTTP 服务器
python3 -m http.server 8000
```

数据自动保存在浏览器 `localStorage` 的 `airline_v2_data` 键中。
